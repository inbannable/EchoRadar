# 耳机采集、识别与界面重构

日期：2026-09-12。目标设备：KZ ZS10 Pro 2、Philips SHP9500，均为 3.5 mm。

## 调研结论与能力边界

两副耳机均通过声卡输出。选择 EchoRadar 的采集设备时，应选择游戏正在使用的声卡播放端点，而不是寻找耳机型号。WASAPI loopback 读取播放端点提供的系统混音；它不是麦克风采集，也不是游戏音源坐标接口。

微软文档说明：软件 loopback 可能复制音频引擎送给硬件的输出，硬件也可能提供 loopback pin。因此，不能承诺采集包含驱动、DAC 或耳机之后的所有处理。需要在实际声卡上对比录音和听感。[Loopback Recording](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording)

虚拟环绕通过 HRTF 在耳机中形成空间线索，空间音频平台可以将对象渲染为双声道耳机输出。由此判断：普通 loopback 返回的双声道不能当成原始 7.1 声道，更不能用简单声道能量推断前后或高度。左右能量显示仅是信号诊断。[HRTF](https://learn.microsoft.com/en-us/windows-hardware/drivers/audio/virtualized-surround-sound-over-headphones)、[Spatial Sound](https://learn.microsoft.com/en-us/windows/win32/coreaudio/spatial-sound)

## 实施计划与本次落地

1. **采集入口**：保持 WASAPI 原生声道，分析端统一 48 kHz。始终打开刚刚检查过的设备 ID，防止默认设备切换时 PCM 与声道掩码错配。固定设备与跟随默认设备均检测声道／采样率变化并重开；指定 ID 时不再回退到同名设备。
2. **声音活动**：增加独立 RMS 活动检测，开启门限 -66 dBFS、关闭门限 -72 dBFS，保持 150 ms；不依赖语义模型，不把 LFE-only 活动误报为没有输入。耳机单独显示左右能量平衡，避免空白环绕雷达误导用户。
3. **事件识别**：有模型时所有雷达显示模式都运行识别；切换显示模式不清除识别上下文。验证概率有限且在 [0,1]，识别器自动处理流代次变化及采样时间断裂。显示推理次数、类别概率与自身声音抑制数量，帮助区分模型未加载、门限未到、事件被抑制。
4. **方向分析**：保留真实 5.1／7.1 声道角色；允许 44.1／96 kHz 等输入在保持角色的前提下重采样至 48 kHz。禁止从立体声升混生成方向证据。输入包中断超过 250 ms 时清除雷达和识别时序状态，并停止绘制旧事件方向。
5. **界面**：深色侧栏与五个独立工作页，按采集／识别／方向分开状态卡；耳机监视器、对数声道电平、设备设置引导、独立 HUD 编辑页。将平台无关绘制移至 DashboardView.cpp；生产界面与离线视觉检查共用同一份绘制代码。
6. **验证**：合成信号覆盖左右、静音、LFE、异常值、声道保真、时间断裂与模型异常；运行现有方向／识别回归套件；使用真实 ImGui 绘制代码生成离线界面预览。Windows 实机和模型准确率须另外验收。

## 尚未完成的完整全景方向路线

本次没有实现「任意双声道耳机混音可靠还原 360°／高度」。这不能通过解除立体声检查或调低阈值完成。后续可选择：

- **渲染前多声道路径**：游戏输出到真实或虚拟多声道播放端点，同时将该流经一次 HRTF 渲染送往现有声卡／耳机。需要解决播放转发、时钟漂移、延迟、设备拔插以及虚拟驱动分发；不能让用户仅勾选 7.1 就宣称完成。
- **针对游戏的双耳模型**：利用目标游戏、HRTF 设置和场景的带方向标注录音训练，测量前后混淆、误差与拒判率。现有识别模型只负责声音类别；本次没有伪造或重新训练模型。

## 两副耳机的 Windows 验收步骤

1. 将耳机插入声卡，记录声卡型号、Windows 版本、游戏、游戏输出设备和空间处理设置。两副耳机分别测试。
2. 在 Audio & headphones 选择同一播放端点。播放左右分离测试音，确认两侧电平和能量显示没有颠倒；用应用现有录音功能保存 PCM 供比对。
3. 先固定一种空间渲染方案（游戏内 HRTF 或系统空间音效），记录设置后分别比较开／关录音。硬件后处理不一定进入 loopback；不要把听感一致当作已验证的原始坐标。
4. 加载现有识别包，在 Continuous、Events、Combined 三种模式检查推理计数持续增长、已知脚步／枪声被检测、抑制原因可诊断。无模型时只有声音活动，不应出现伪语义事件。
5. 有真实 5.1／7.1 输入时，按角色依次播放测试音，检查扇区；双声道只显示能量平衡，前后角度应保持不可用。
6. 暂停播放、切换默认设备、修改原设备格式、拔插声卡，检查自动恢复、不残留旧方向、不混合录音文件的声道布局。
7. Windows 100%／150%／200% DPI 检查所有页面、中文设备名、窗口缩放、HUD 拖动和穿透。离线预览不替代 DirectX／DPI 实机检查。
